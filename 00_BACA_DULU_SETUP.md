# WHAT IF WORLD HQ — PAKET V2 (UNTUK CHATGPT PROJECT)

Paket ini menggantikan paket sebelumnya. Tujuannya: begitu kamu membuka project dan mengirim satu pesan apa pun, AI langsung memberi 5 alternatif ide; setelah kamu memilih, AI mengerjakan seluruh paket produksi sampai selesai.

## Isi file
1. `01_INSTRUKSI_PROJECT.md` — tempel ke kolom Instruksi Project (ringkas, ±6.000 karakter).
2. `02_PANDUAN_PRODUKSI_UTAMA.md` — standar produksi permanen (unggah).
3. `03_TEMPLATE_PRODUKSI.md` — template tiap video (unggah).
4. `04_WW-001_PAKET_PRODUKSI_V2.md` — paket lengkap WW-001 versi perbaikan (unggah). Bisa kamu kerjakan langsung tanpa AI.
5. `05_ARSIP_KONTEN.md` — ingatan project + bank ide (unggah; diganti setiap selesai produksi).

## Setup (sekali saja)
1. Buka ChatGPT → buat/buka Project **WHAT IF WORLD HQ**.
2. Hapus instruksi lama, tempel isi `01_INSTRUKSI_PROJECT.md`.
3. Unggah file 02, 03, 04, 05 ke Project Files (file 00 tidak perlu).
4. Aktifkan pencarian web (agar riset dan sumber nyata).

## Cara pakai
1. Buka chat baru di project → ketik apa saja, mis. **"mulai"**. (AI tidak bisa bicara lebih dulu; satu pesan darimu diperlukan.)
2. AI memberi 5 ide + rekomendasi. Balas angka **1–5** atau **"terserah"**.
3. AI mengerjakan semuanya: riset, uji fisika, cerita, referensi, keyframe, prompt video, narasi + brief TTS, musik, SFX, subtitle bertimecode, editing, paket TikTok, QA, arsip. Jika terpotong, ketik **"lanjut"**.
4. Di akhir, AI memberi isi baru `05_ARSIP_KONTEN.md` → ganti file lama di Project Files.

## Bagian yang tetap kamu kerjakan (AI tidak bisa)
1. Buat gambar referensi lalu keyframe (alat gambar Flow/lainnya).
2. Uji dulu klip 1–2 (bandingkan Ingredients vs Frames to Video), baru render sisanya. Semua klip = silent plate.
3. Rekam narasi dengan TTS dalam satu pass memakai brief dari AI; buat musik dengan prompt musik.
4. Rakit di editor (CapCut dll.): trim klip 8 detik, pasang narasi, musik, SFX, overlay teks dan subtitle sesuai peta timecode.
5. Cek QA (terutama blocker), lalu unggah ke TikTok dengan label konten buatan AI aktif.
6. Jika hasil render bermasalah, kirim deskripsi/gambar masalahnya ke AI → mode revisi akan memberi prompt pengganti.

## Yang berubah dari V1 (dan alasannya)
- Fisika diperbaiki: cahaya padam seketika setelah jeda 8 mnt 20 dtk; yang bertahap adalah pendinginan.
- Hook baru: bintang di siang bolong, bukan pagi tenang.
- Audio: semua klip silent plate; narasi TTS satu pass; satu musik bed (tes pertama gagal di audio Flow).
- Teks: semua overlay saat editing, bukan dibuat model.
- Referensi: gambar tunggal, ada varian siang/gelap, tak ada properti pajangan, tak ada karakter tanpa referensi.
- Prompt dipangkas: satu aksi + satu gerakan kamera per klip; ada Plan B.
- Durasi: klip dirender 8 dtk (Veo 3.1 menawarkan 4/6/8 dtk; mode Ingredients/Frames biasanya terkunci 8 dtk) lalu di-trim.
- Kelengkapan: tabel sains, peta subtitle, timeline, QA berskor, label AI TikTok, premis hipotetis di video.

## Batas jujur
- AI tidak merender, mengedit, atau memposting. Kemampuan Flow berbeda antar akun/model/mode — uji dulu.
- Angka sains di WW-001 sudah dicek silang, tetapi tetap verifikasi sumber primer sebelum tampil di layar.
- Skor QA di paket adalah skor rencana; skor video diisi setelah render. Ini rubrik editorial, bukan prediksi performa TikTok.
- Bila pesan "mulai" tidak langsung memberi ide, ketik: "Ikuti bagian PERILAKU PERTAMA di instruksi project."
